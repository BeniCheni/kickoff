## The concept (one paragraph)

Three lenses over one skeleton — **Ledger** (default; the Table's quiet language extended to
fixtures), **Poster** (loud day headers and a tonight's-slate hero; rows stay Ledger rows), and
**Broadcast** (dark-first, floodlight amber leads, live ticker strip, glow on hot rows). A lens
may change only four things: atmosphere (default theme + leading accent), day-header scale, row
density/type scale, and the hero element. Everything else — shell, tab row, filter chips,
Weekly/Monthly control, two-clock rendering, provenance/staleness callouts, competition colors,
the Table screen, the footer — is invariant. The Table never changes with lens.

## Build spec

### 1. Lens state & plumbing
- `?lens=` via `useUrlState`: `'ledger' | 'poster' | 'broadcast'`, default `ledger` omitted from
  the URL, invalid values → `ledger`. Use `replace` history (a view preference, not navigation —
  tab switches keep their `push`).
- Reflect the lens as `data-lens` on `<html>` (like `data-theme`), and add a Tailwind custom
  variant per lens in `index.css` (same pattern as the existing `dark` custom-variant) so
  components can say `broadcast:...` where a class swap is cleaner than a conditional.
- **Broadcast theme default:** entering Broadcast with no stored theme choice *for Broadcast*
  sets dark; if I toggle back to light while in Broadcast, remember that and don't re-force
  dark on the next entry. Leaving Broadcast restores whatever the non-Broadcast theme choice
  was. Keep the mechanism simple (a second localStorage key is fine), set it before paint in
  `main.tsx` like the existing theme bootstrapping, and unit-test the decision function.

### 2. LensSwitcher (new component)
Per the templates: a segmented pill on the tab-row line, right-aligned (`margin-bottom:8px` to
sit on the shared hairline) — `LEDGER · POSTER · BROADCAST`, Oswald 600 caps 10px, 0.1em
tracking, `1.5px` `line-strong` border, `radius 9999`, active segment filled with the lens's
leading accent: **pitch** (Ledger), **ink** (Poster), **floodlight** (Broadcast), inactive
segments `ink-muted`. A11y: `role="radiogroup"`, arrow keys move selection, visible focus ring
in the active lens accent. Motion: the thumb/fill change animates 180ms
`cubic-bezier(.2,.7,.2,1)`; on lens change the page cross-fades by transitioning token-driven
colors 220ms (a transient `lens-switching` class on the root that enables
`transition: background-color 220ms ease, color 220ms ease, border-color 220ms ease` and is
removed after the fade — do not leave global transitions permanently on). Under
`prefers-reduced-motion`, both collapse to instant. On 390px, if the switcher + tabs can't share
the line, the switcher drops to its own right-aligned line directly under the tab row — check at
390px and pick what actually fits.
On the **Table tab** the switcher stays visible but quiet (it still switches, the Table just
doesn't change) — exactly as the brief says; the Broadcast ticker strip does **not** render on
the Table tab.

### 3. Ledger lens (default — this replaces the current week view look)
From `Ledger.dc.html`:
- **Date spine:** two-column grid `56px + 1fr`, `column-gap 12px`. Left: weekday caps 10px
  muted, day numeral Oswald 600 **30px** (today's numeral + Today pill in `pitch`), rows column
  starts with a `1px line` top border.
- **Rows on hairlines, not cards:** each row `border-bottom 1px line`, `padding 8px 0 8px 9px`,
  leading Brooklyn time in Plex Mono 500 13px `ink-secondary` `min-width 58px`, then teams
  13.5px/600, FT score in mono `pitch`, status pills as today. Competition + venue meta line
  11px muted beneath. Marquee rows: 3px absolute left rail in the **competition color**;
  postponed/cancelled: `accent` rail. Row expansion (tap → the second line with both clock
  pills, note, TV pill) animates 150ms ease. TBC rows keep the amber italic line verbatim.
- **Empty days collapse:** weekday + small numeral (16px, muted) on one line, a single hairline
  row containing `—` (mono 11px muted). Days fully hidden by filters: same treatment with
  `🔎 n hidden by filters`.
- **Hero — Next-up strip replaces the 200px ticker:** 4 equal `flex:1 min-width:0` cards
  (surface, 1px line border, **3px bottom border in competition color**, radius 4): label caps
  9px (Today/Tomorrow/`n days`), Plex Mono 600 15px Brooklyn time, one-line truncated teams
  10.5px. Below: `+n more today · <next fixture>` line, 10.5px muted. Marquee gradient stays
  ticker-only history — no gradients here.
- The current `Ticker.tsx` (200px cards) is retired on all lenses; `WatchPanel`, `FilterBar`,
  Weekly/Monthly control, period nav, `StalenessBanner`, footer: unchanged.

### 4. Poster lens
From `Poster.dc.html` — rows stay Ledger rows except the leading time:
- **Hero "Tonight's slate":** full-bleed block (negative gutter margins), `surface-alt` with a
  **12px left rail in the day's dominant competition color**, "TONIGHT'S SLATE" caps 11px,
  day title Oswald 700 **40px**, mono sub-line `n REMAINING · FIRST h:mm · LAST h:mm`
  (11px, 0.06em tracking), then remaining fixtures as `4px` competition-rail rows with mono
  **24px** time. If today is empty, show the next matchday and say so.
- **Day headers, loudness proportional to the slate:** big days get the full-bleed duotone
  header (`surface-alt` + 12px dominant-competition rail, Oswald 700 44px for today /
  28px otherwise, mono sub-line `n MATCHES · n LEAGUES · FIRST KICKOFF h:mm`); days with ≤2
  matches get a small inline header (Oswald 600 16px + mono match count); consecutive empty
  days merge into one hairline line: `TUE 1 · WED 2 — NO FIXTURES` (mono 11px muted).
  "Dominant competition" = the competition with most fixtures that day; ties break toward the
  marquee (non-domestic) one.
- **Rows:** Ledger anatomy with Plex Mono 600 **20px** time, `min-width 82px`; meta line
  indented to align under teams (`padding-left 92px`).

### 5. Broadcast lens
From `Broadcast.dc.html`:
- **Atmosphere:** floodlight amber replaces pitch as the leading accent *within this lens only*:
  tab underline `inset 0 -2.5px 0 var(--floodlight)`, Today pill amber (`color: var(--bg)`
  text), day numerals amber, switcher thumb amber, focus rings amber. Implement via
  `data-lens="broadcast"`-scoped CSS/variant, not by editing base tokens. Pitch remains for
  scores/confirmed. Both themes must work; dark is the default per §1.
- **Ticker strip** (new component, Fixtures tab only): full-bleed single line under the tab
  row — `surface` bg, 1px bottom line, mono 11px `ink-secondary`, amber 600 keywords
  (LIVE/NEXT/FT), `·` separators, live minute like `67′`. Marquee: duplicated content span,
  `@keyframes` translateX 0 → −50%, **36s linear infinite**; pauses on hover/touch
  (`animation-play-state: paused`), static (no animation, content simply overflows hidden)
  under `prefers-reduced-motion`. Built from the loaded snapshot: live fixtures, next kickoff,
  today's FT scores. This marquee plus §2's timings are the *complete* motion budget — nothing
  else animates.
- **Glow:** rows that are LIVE or the next kickoff get `data-hot`: `background: var(--surface);
  box-shadow: 0 0 14px var(--glow)` (add `--glow` to `index.css`: light
  `rgb(201 138 0 / 0.18)`, dark `rgb(247 201 72 / 0.18)`). Nothing else glows.
- **Rows:** Ledger geometry, mono-heavier per the template (times/numerals unchanged in size,
  tighter leading).

### 6. Month view (all lenses — replaces dots-aren't-data)
Grid cells show the match count (mono) and up to three competition-colored short bars; marquee
days get a ⭐; selecting a cell reveals that day's rows (in the current lens's row style)
beneath the grid, 150ms ease. The duplicate full list below the grid is removed — the grid is
now the navigation. Month view is lens-invariant apart from row styling and accents inheriting
the lens.

### 7. Sanctioned non-lens items (tiny, do these too)
- Favicon: copy from `../Fergie Time Design System/assets/favicons/` into `public/`, wire in
  `index.html` + a `<link rel="apple-touch-icon">`.
- Header version string: read from `package.json` via Vite `define`; delete the hardcoded
  `v0.0.1`. Bump `package.json` version to `0.0.3`.
- Provenance line format per templates: `v0.0.3 · 959 fixtures · synced 2026-08-30 17:02 UTC`
  (values live, of course).

### 8. Hard rules (unchanged, enforced)
Never render a kickoff time the league hasn't set (amber italic TBC line verbatim); never
invent matchday numbers or data; both clocks from one UTC instant on every non-TBC fixture;
amber only ever means data provenance/caution — except Broadcast's sanctioned lens-wide accent
promotion; no new gradients (marquee ticker-card gradient is retired along with `Ticker.tsx` —
`--marquee` tokens may be removed if nothing else uses them, note it in the PR); Table screen
and its components untouched; no new dependencies, no router, no state library.

## Process & verification

- Branch `claude/kickoff-v0.0.3-lens-system` off up-to-date `main`. Commit in reviewable units
  (plumbing → Ledger → Poster → Broadcast → month view → chores). PR to `main` when green;
  PR body: summary, screenshots, deviations list (template-vs-brief resolutions, anything you
  chose), and what was deliberately not done.
- `npm run typecheck` and `npm test` green at every commit. Existing 32 tests keep passing —
  where a redesign breaks a rendering assumption in a test, fix the test to the new truth, never
  by weakening a data-honesty assertion.
- New unit tests: lens URL parse/serialize (round-trip + junk input), the Broadcast
  theme-default decision function (all four entry cases), dominant-competition-of-day picker
  (tie → marquee), the hot-row (LIVE/next-kickoff) selector, month-cell aggregation
  (count + top-3 bars).
- Run the dev server and **verify in the browser before declaring done**: all 3 lenses × 2
  themes × 2 tabs, at 390px and ~1000px; lens transition smoothness; ticker pause on hover;
  reduced-motion pass (emulate via devtools); keyboard walk of the switcher; deep links
  (`/?lens=broadcast&tab=table`, `/?lens=poster&date=...&only=pl,laliga`) reload correctly;
  Back button behaves (lens replace, tab push). Screenshot each lens (mobile, both themes for
  Broadcast) into the PR.
- A11y: contrast AA for text in every lens × theme you touched — flag any pair that fails
  rather than silently darkening a token.

## Out of scope (do not build)
Results tab, "what moved" panel, anchors/betting overlays, team pages, PWA manifest, deployment,
sync changes, Table restyling. If something in scope genuinely requires touching an
out-of-scope file, stop and ask.
