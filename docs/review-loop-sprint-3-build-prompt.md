PART D — AUTHORIZE. elenchus authorize <pr> posts the configured status context, state success, on the pull request's head, as the App, when and only when: every configured pass has a valid record (the latest re-read standing for its pass); check has no FAIL and no UNVERIFIED the configuration marks as blocking; the head equals the last recorded output_sha, or every commit after it is in D3's allowed set; and every configured check is green at the head.
