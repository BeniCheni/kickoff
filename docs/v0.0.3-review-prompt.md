## Review method — verify, don't vibe

**Static pass.** Read every new/changed file completely (`lens.ts`, `theme.ts`,
`lensSelectors.ts`, `App.tsx`, `main.tsx`, `index.css`, `LensSwitcher`, `TabNav`,
`LedgerWeek`, `PosterWeek`, `TonightSlate`, `NextUpStrip`, `TickerStrip`, `FixtureRow`,
`MonthView`, `WeekView`, `FixturesPage`, the tests). Hunt these classes specifically:

- **Data honesty** — the house religion. Can a postponed/cancelled fixture surface anywhere
  wearing its dead kickoff time? Can a TBC placeholder leak a confident number into any
  sub-line, ticker segment, hero card or bound (FIRST/LAST)? Is anything invented (live
  minutes, matchday numbers)?
- **URL & history** — `?lens=` parse/encode totality, replace-vs-push semantics, Back/Forward
  via popstate, deep links (`/?lens=broadcast&tab=table`, `?lens=poster&date=…&only=…`),
  junk-input fallbacks.
- **Theme memory** — the Broadcast dark-default decision in all four entry cases; toggle
  storage keys; the pre-paint bootstrap vs App's effect (can they disagree?); StrictMode
  double-effects; note that the no-stored-choice default now follows `prefers-color-scheme`
  (a deviation from "cream is default" — judge it, don't just accept it).
- **A11y & contrast** — radiogroup keyboard behavior; focus visibility; AA on every NEW
  color pairing per lens × theme (be suspicious of anything set on amber, which is light in
  both themes).
- **Motion budget** — 150/180/220ms plus the sanctioned ticker marquee and nothing else;
  reduced-motion collapses everything; no permanently-enabled global transitions.
- **Staleness traps** — `new Date()` captured in mount-time memos (hot rows, ticker,
  countdowns); what goes wrong in a tab left open overnight?
- **Invariants** — Table untouched, chips/filters/staleness/footer identical across lenses,
  competition colors never theme-shifted.

**Dynamic pass — mandatory, in a real browser.** Build, serve, and drive it (Playwright or
the preview pane): all 3 lenses × 2 themes × 2 tabs at **390px and 1000px**; verify
`document.documentElement.scrollWidth === viewport width` on every screen (no horizontal
scroll, ever); the lens cross-fade; ticker pause on hover and its reduced-motion fallback;
keyboard walk of the switcher; Back/Forward behavior. Treat the PR's committed screenshots
skeptically — re-capture rather than trust (set the viewport first and check scrollWidth
before capturing; a clipped capture is not evidence of a layout bug, and a pretty capture is
not evidence of health).

## Fix policy

- Fix what you can **verify** (reproduce or demonstrate), in scope: correctness, honesty,
  a11y/AA on new surfaces, layout defects, small structural cleanups the fix naturally
  touches. Every behavioral fix gets a test where the logic is pure.
- No feature creep: no Results tab, no live data fetching, no "what moved" panel, no Table

  component-level pairing), flag it for the design system instead.

## Appendix — leads from an earlier partial review (verify independently; trust nothing)

A prior review pass of this PR (later reverted, no commits remain) reported these. Re-derive
each yourself before acting — if one doesn't reproduce, say so rather than fixing ghosts:

- `upcoming()` in `src/lib/fixtures.ts` filters only `status !== 'full_time'`, so a
  postponed/cancelled match can appear as a "Next up" card with its dead kickoff time.
- Light-theme Broadcast sets cream text on amber fills (Today pill, active switcher segment,
  LIVE pill) at ≈2.6:1 — fails AA; amber is light in both themes, so text on it wants to be
  near-black in both.
- At 390px the lens switcher wraps below the tabs inside the bordered nav, leaving the
  active-tab underline floating mid-nav instead of kissing the shared hairline (the two tabs
  can also wrap apart if the group isn't atomic).
- `TonightSlate` prints `FIRST h:mm · LAST h:mm` with the same time when the slate has one
  kickoff.
- Flagged, not fixed there: light floodlight `#C98A00` sits ≈2.6–2.9:1 on cream/white at
  small sizes app-wide (palette-level, predates this PR); the ticker renders LIVE from the
  last sync, honest only alongside the staleness banner; the system-preference theme default
  is an undocumented deviation from the brand book.
