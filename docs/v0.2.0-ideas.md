# v0.2.0 — candidate work, from the v0.1.0 review

Written cold for whoever scopes the next release. Everything here was judged *real* during
the adversarial review of PR #2 (the lens system, shipped as v0.1.0) and *out of scope*
there. Ranked by research value × feasibility; sizes are rough (XS < an hour, S < half a
day, M ≈ a day or two).

*Restaged from `v0.1.1-ideas.md` when PR #4 shipped as the v0.1.1 housekeeping patch: the
list below is feature and behavior work — minor-bump material under semver — so the next
release that draws from it is v0.2.0, not another patch.*

## Process notes — how future PRs should verify themselves

Things this review proved about the *method*, written down so they don't need re-proving:

- **Screenshot the whole matrix.** The PR shipped 4 of 6 lens × theme combos; Ledger-dark
  and Poster-dark — exactly the combos never captured — were where the untested var
  indirection lived. All six, every time, at 390px.
- **Assert, don't admire.** `document.documentElement.scrollWidth === innerWidth` on every
  screen; computed-style reads for every color claim; a contrast script over every new
  pair in both themes. A pretty capture is not evidence of health.
- **390 is the judge, 360 is the jury.** The switcher wrap "at 390px" actually fit 390
  with zero pixels of slack and broke at ≤374px — including 360px, the most common
  Android width. Test 360/375/390/1000 and know where the zero-slack points are.
- **Absolute words in comments are review bait.** "Never", "complete", "so the two can
  never disagree", "fits a 390px viewport" — each absolute claim in a doc comment was
  falsifiable and most were false. Treat them as assertions needing a test.
- **Test past the module boundary.** The PR's 28 new tests were good and stopped exactly
  where the bugs lived (`upcoming`, the `date`/`only` decoders, single-fixture bounds).
  If logic sits inline in a component, extract it to `lib/` and test it there.
- **Latent paths need synthetic data.** The snapshot currently holds zero postponed or
  cancelled fixtures, so no amount of manual QA exercises those branches. Unit tests with
  fabricated fixtures are the only coverage they can get.
- **Hidden-tab measurement gotcha.** CSS transitions never advance while
  `document.visibilityState === 'hidden'` — computed styles read mid-transition values
  indefinitely, which looks exactly like a broken cascade. Flush with
  `document.getAnimations().forEach(a => a.finish())` (skip infinite animations) or
  measure on fresh loads.
