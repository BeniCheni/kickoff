Precedence: the Fergie Time design system › the D6 brief › any implementation prompt written from this. Nothing here claims a release number.

A frame on the canvas is a static receipt. It proves geometry, copy, contrast and accessible names; it does not prove playback, a browser’s autoplay policy, Supabase’s behaviour, a pull request’s checks or a state machine, and nothing below says it does. Values marked **measured** come from a file or a receipt named here; values marked **ILLUSTRATIVE** are invented for illustration and must not be copied into a record as fact — and each one is tagged beside where it is drawn (D-47, completed in D8: titles, dates, notes, Up next rows, the Billed column, the Unpublish step times). - **No cards without the list.** When the server cannot read the database — including a paused Free project, which takes the database and Storage down together — the gallery shows the unavailable block and no cards (`3-*`). The protection against a pause is Supabase’s Pro plan, Beni’s decision before going public; not this copy.
- **One element, one host; the thumbnail before Play; the video file not requested until Play** (D-49). `poster` stays unset so the three-step chain governs the before-Play picture.
- **Every address comes from the record — Q23 Stored.** Publish writes the bucket and object path of the video and the thumbnail into the record; the site reads them back and never builds one. The build’s shape is bucket `moments`, `<public id>/video-<sha8>.mp4`, `<public id>/thumbnail-<sha8>.jpg`, each object’s content type set at upload apart from its name (**D9**, D-59); the design does not depend on the shape, only on the rule.
