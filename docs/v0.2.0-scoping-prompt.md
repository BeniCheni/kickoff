## Standing rules for anything you commit (Phase 0's merge included)

- `npm run typecheck` and `npm test` green at every commit.
- **Data-honesty test assertions are never weakened to make a change pass.**
- `src/data/*.json` is written only by `npm run sync`. Never hand-edit it. Code paths needing
  postponed / cancelled / abandoned / suspended fixtures get **synthetic test fixtures** — the
  live snapshot holds none, so unit tests are the only coverage those branches can get. This
  applies directly to #3: the statuses you're mapping cannot be exercised by the real data.
- Commits authored as `Claude <noreply@anthropic.com>`. Match this repo's commit voice — read
  `git log` first.
- Browser-verify before declaring anything done: every lens × theme × tab at **360, 375, 390 and
  ~1000px**. 390 is the judge, 360 is the jury — the v0.1.0 review found a wrap that fit 390
  with zero pixels of slack and broke at 374. Set the viewport *before* capturing and assert
  `document.documentElement.scrollWidth === window.innerWidth`. A pretty screenshot is a claim,
  not evidence.
- Color changes get a computed-style read and a contrast check in **both** themes. Component-
  level AA fixes are fair game; token-level repaints are a design-system decision — flag them,
  don't make them.
