# Moments media direction

Read for Moments gallery, cinema, cover or playback design. Turn capability evidence into
visible product behavior; a provider name or an attractive card proves no playback capability.

## Distinct uses and evidence

Keep a small source ledger for the sample: asset identity, fixture/moment match, official source
or rights basis, intended use, observed capability, check time/context and unresolved limits.
Consult current provider documentation and asset-specific evidence for the intended use; do not
copy historical provider requirements into permanent design rules.

| Use | What must be distinguished |
|---|---|
| Provider link | A destination, not an inline player or proof that the video was watched. |
| Embeddable player | Provider-supported playback observed in a named environment; metadata or an iframe alone is insufficient. |
| Thumbnail | Permission to display this image, distinct from downloading or transforming it. |
| Still | A permitted image with its own source/credit; attribution alone grants no rights. |
| Preview loop | Permission to create/display moving excerpts; neither a still nor an embed grants it. |
| Hosted video | Rights to download, store and redistribute the video within the relevant scope. |

Public availability, an uploader's attribution or an unofficial repost's licence label does
not establish underlying broadcast rights. Do not bypass provider blocks, hide provider
controls/ads, or promise universal availability. Unknown failure and confirmed geographic or
rights restriction need different wording. Keep source provenance readable and details accessible.

## Whole-video gallery contract

Distinguish these states both visibly and in text/accessibility labels, not through color alone:

- **Simulated playback:** mark the prototype/player as simulated; animation is not footage proof.
- **Verified provider playback:** name the provider and record the actual playback observation;
  this is time/context bounded, not a permanent rights warranty.
- **Blocked media:** state the observed limitation, keep context, and offer an honest skip or
  available provider destination. Do not diagnose a territorial block from an unknown error.
- **Link-out content:** use an action such as “Open at [provider]”; avoid a misleading play-here icon.
- **Original fallback cover:** label it as original artwork, not a match still. The cover label
  is separate from playback status: an original cover can accompany any of the states above.

An edition promising every card plays here must limit eligibility to supported inline sources;
keep link-only content separately labelled and publish fewer items if needed. A verified source
can later fail, so retain failure states. Several cue points in one compilation are not several
distinct videos; only assert cue points, scorer/minute or quality judgments supported by evidence.

Explore covers with Fergie Time type, spacing and competition identity. Abstract football geometry
can supply atmosphere; fabricated trajectories or generated match scenes cannot supply facts.
Compare cover cropping separately from playback framing, with provider controls unobscured.

In a requested prototype, exercise intentional play, one active player, next/previous, pause,
close/return and blocked recovery. Preserve active item and queue position during shuffle;
honor filters and duplicate handling. Test keyboard/focus return and reduced-motion equivalents.
Record whether each interaction was simulated or exercised through the provider. Hand uncertain
player sizing, privacy/loading, media permissions and availability behavior to feasibility work.
